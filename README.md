# What Do You Love? 🎨

A procedural, hand-drawn paper-cutout animation recreation of the viral piece *"What Do You Love?"* (originally created by Kevin Ngo).

Every single visual element—from the torn paper edges, the notepad, the characters, and the cosmic elements—is drawn frame-by-frame on an HTML5 `<canvas>` using pure JavaScript, paired with a synchronized real-time procedural Web Audio soundtrack.

## ✨ Features
- **100% Procedural Canvas Rendering**: Zero external image or font files.
- **Paper Cutout Aesthetic**: Organic torn-paper edges with seeded fractal jitter and soft drop shadows.
- **Real-Time Web Audio**: Warm, melodic music box & piano synthesis running on the browser's `AudioContext`.
- **Full Storyboard**:
  1. Hand writing *"what do you love?"* on a spiral notebook and tearing the page off.
  2. The girl folding and launching the paper airplane out into the night.
  3. Starry sky flight where the paper airplane reaches Claude.
  4. Claude unfolds and reads the note.
  5. The 4 vignettes: *"words"*, *"trees"*, *"rain"*, and *"the stars"*.
  6. The giant pink collage heart burst with all of life's memories orbiting.
  7. Claude folding the note back and sending it home.
  8. The note unfolded: **"[you]"** circled in warm orange crayon with Claude's starburst.
  9. The glowing town at night, with the girl waving from her illuminated window and Claude shining bright above.
- **Mobile-Optimized**: Touch controls, fullscreen mode, responsive aspect ratio, and iOS Safari audio unlock.
- **Built-in Video Exporter**: Record directly to WebM or export frame snapshots as PNG.

## 🚀 Running Locally
Open `index.html` in any modern web browser or serve via:
```bash
python3 -m http.server 8080
```
